# barteron-categories-generator

## Скрипт для создания категорий в бартероне

### Инструкция:

**1. Скопировать из бартерона файлы:**
- `/src/data/categories.json` в `/input/existing/data/categories.json`
- `/src/i18n/en-US/categories.json` в `/input/existing/i18n/categories.json`

*Первый файл нужен для контроля уникальности id и для проверки, чтобы id был, если категория существует, но в нее надо добавить дочерние. Второй файл нужен чтобы удалить дубли ключей локализации, если окажется совпадение ключей в создаваемых категориях и в существующих. Поэтому достаточно en-US файла.*

*Данную процедуру необходимо выполнять при каждом создании категорий. Т.е. если надо создать (или расширить существующие) несколько категорий, то после создания (расширения) первой категории надо поместить результат в бартерон (см. следующие шаги алгоритма), а затем приступать к созданию (расширению) новой категории, снова выполняя эту процедуру. В этом случае алгоритм будет корректно подбировать значения `id` для подкатегорий и удалять дубли ключей локализации, сообщая об этом в консоль в виде предупреждения.*

**2. Вставить в директорию `/input` исходные файлы для формирования категорий и локализации.**

*Данные файлы должны содержать описание вложенности категорий с помощью символов отступа (см. следующий пункт, параметр `shift`). Название файла должно быть в виде language-REGION.txt. Пример: `en-US.txt`.*

**3. Задать inputParams таким образом:**

- `id` - это идентификатор создаваемой категории. 

*Если это новая категория, надо выбрать уникальное значение. Желательно чтобы оно было таким, чтобы после него был свободный диапазон значений данного параметра для всех дочерних категорий и небольшой запас на случай добавления новых дочерних категорий.*

**ВАЖНО!** *Если же категория есть в бартероне, но требуется создать дочерние категории, то id должен быть равен исходному значению, иначе существующие объявления в данной категории не будут корректно функционировать.*

- `isNew` - булево значение, равное истина, если это новая категория.

*Это значение необходимо алгоритму для проверки значения id, как указано выше.*

- `order` - значение используется для сортировки категории. 

*Если создается новая категория, то надо выбрать уникальное значение среди категорий верхнего уровня. Если категория существует, то надо скопировать значение из бартерона*

- `icon` - название иконки для категории из библиотеки fontawesome.

*Для существующей категории данное значение нужно скопировать из бартерона, для новой - подобрать подходящую.*

- `shift` - последовательность символов, используемая в качестве обозначения отступа для описания вложенности подкатегорий.

**ВАЖНО!** *Рекомендуется использовать четыре знака умножения для обозначения одного уровня вложенности. Например, google-переводчик корректно работает с данными символами, оставляя их при переводе, а четыре символа хорошо читабельны. Если же использовать последовательность из знаков "-" для той же цели, то иногда данный переводчик может увеличить их количество в начале строки.*

- `keyFileName` - название файла (без расширения) в директории `/input`, которое будет использоваться алгоритмом для формирования ключей локализации.

**ВАЖНО!** *Данное значение должно быть en-US, т.к. ключи локализации в бартероне даны на анлгийском языке.*

- `fileNames` - массив названий исходных файлов в директории `/input` без расширений.

*Данные значения задаются в виде language-REGION. Пример: `en-US`.*

**4. Запустить алгоритм и проверить результат работы (файлы в директории `/output`).**

*При успешном выполнении алгоритма в консоль должно быть выведено `SUCCESS!`. В случае возникновения ошибки будет выведено `FAILED! <описание ошибки>`.*

**5. При успешном завершении алгоритма скопировать тело JSON из файлов директории `/output` и вставить (либо заменить в случае расширения категории) скопированные строки в соответсвующие файлы в бартероне.**

**ВАЖНО!** *После выполнения данного шага необходимо запустить бартерон и проверить корректность внесенных изменений.*
